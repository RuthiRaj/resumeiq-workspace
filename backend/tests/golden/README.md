# Golden fixtures

Everything in this directory is **synthetic**. The people, employers, dates,
numbers, emails and phone numbers are invented for tests and for the B3
bake-off (`backend/scripts/ai_bakeoff.py`).

Rules:

- never add real personal data, a real resume, or a real contact detail;
- keep using reserved domains (`example.com`) and reserved-looking numbers
  (`555`), so an accidental live AI call cannot leak a real person's data;
- fixtures are committed, so treat them as public.
